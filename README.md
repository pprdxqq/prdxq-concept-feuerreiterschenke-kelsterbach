# Feuerreiterschenke — independent PRDXQ concept

This is an independent, uncommissioned website concept. It is not the official website of the Feuerreiterschenke and does not imply approval or a client relationship.

## Scope

- Three static pages: `index.html`, `gaststaette.html`, and `besuch.html`.
- Responsive navigation, click-to-call contact, and a map handoff.
- No forms, analytics, cookies, external images, or backend services.
- Custom CSS illustration and favicon; no business logo or venue imagery was copied.
- The site intentionally omits a menu, prices, exact opening hours, and reservation promises because current primary-source confirmation was unavailable.

## Verified information and limits

The address and restaurant category appear in public business listings. The number 06107 64579 is listed by Das Telefonbuch and meinestadt.de. Cylex has the same address but shows a conflicting number, so the concept labels the phone number as directory sourced and calls for owner confirmation before official use. Public directory listings contain differing opening hours and are not treated as authoritative.

The directory-linked official domain returned HTTP 500 during a direct request on 2026-10-16. That proves the checked page was unavailable at that time; it does not establish the condition of any archived site or internal business system.

## Run locally

Open `index.html` in a browser or serve this folder with any static file server. There is no build step.

## Deploy

GitHub Pages deploys the repository root using `.github/workflows/pages.yml`.

## Before any official use

Obtain the business's approval, verify the operator's preferred spelling and contact number, confirm menu and opening-hour details, and add owner-approved legal/provider information. No production legal text is included in this concept.
